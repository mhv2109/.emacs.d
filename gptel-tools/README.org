* Overview

=gptel-tools= is an Emacs Lisp package that extends [[https://github.com/karthink/gptel][gptel]] with additional tools for enhanced AI interaction. The package provides tools for searching org-mode notes, RSS feeds, and PDF files, making it easier to integrate external content into your AI conversations.

* Features

- *Deft Integration*: Search org-mode notes using deft with TF-IDF similarity scoring
- *Elfeed Integration*: Fetch RSS feed headlines and entries
- *PDF Processing*: Extract text content from PDF files
- *TF-IDF Implementation*: Custom text vectorization for document similarity

* Installation

** Requirements

- Emacs with =lexical-binding= support
- [[https://github.com/karthink/gptel][gptel]]
- [[https://github.com/jrblevin/deft][deft]] (for note searching)
- [[https://github.com/skeeto/elfeed][elfeed]] (for RSS feeds)
- =pdftotext= command-line utility (for PDF processing)

** Manual Installation

1. Clone or download the repository to your =~/.emacs.d= directory
2. Add to your Emacs configuration:

#+BEGIN_SRC emacs-lisp
(add-to-list 'load-path "~/.emacs.d/gptel-tools")
(require 'gptel-tools)
#+END_SRC

* Available Tools

** Deft Search Tool

*** =deft_search_files=

Searches org-mode notes using deft and returns results with TF-IDF similarity scores.

*Arguments:*
- =term= (string): Search term for file contents

*Returns:* JSON object with files and similarity scores

*Example usage in AI conversation:*

#+END_EXAMPLE

** Elfeed RSS Tools

*** =elfeed_get_headlines=

Returns news headlines from your Elfeed RSS feeds.

*Returns:* JSON object with headlines array

*** =elfeed_get_entries=

Returns news headlines with their corresponding URLs from Elfeed RSS feeds.

*Returns:* JSON object with entries containing titles and links

*Example usage in AI conversation:*
#+BEGIN_EXAMPLE
What are the latest news headlines?
#+END_EXAMPLE

* Implementation Details

** TF-IDF Vectorization

The package includes a complete TF-IDF (Term Frequency-Inverse Document Frequency) implementation written in Emacs Lisp:

- Tokenization with stop word removal
- Document frequency calculation
- Cosine similarity computation
- Configurable maximum features and custom stop words

* Configuration

** Deft Configuration

Ensure deft is properly configured with your notes directory:

#+BEGIN_SRC emacs-lisp
(setq deft-directory "~/notes")
(setq deft-extensions '("org" "md" "txt"))
#+END_SRC

** Elfeed Configuration

Configure your RSS feeds in elfeed:

#+BEGIN_SRC emacs-lisp
(setq elfeed-feeds
      '("https://example.com/feed.xml"
        "https://another-site.com/rss"))
#+END_SRC

** PDF Tool Requirements

Install =pdftotext= (usually part of poppler-utils):

#+BEGIN_SRC bash
# Ubuntu/Debian
sudo apt-get install poppler-utils

# macOS
brew install poppler

# Arch Linux
sudo pacman -S poppler
#+END_SRC

* Troubleshooting

** PDF Tool Not Working

If the PDF tool doesn't initialize, ensure =pdftotext= is installed and available in your PATH:

#+BEGIN_SRC bash
which pdftotext
#+END_SRC

** Deft Search Issues

Make sure your deft configuration is correct and your notes directory exists:

#+BEGIN_SRC emacs-lisp
(deft-refresh)  ; Refresh deft file cache
#+END_SRC

** Elfeed Empty Results

Ensure elfeed has fetched content:

#+BEGIN_SRC emacs-lisp
(elfeed-update)  ; Update all feeds
#+END_SRC
